# DoneDeal Ireland Scraper

Extract listings from DoneDeal.ie, Ireland's largest classifieds marketplace.

## Features

- Multi-category support: cars, property, jobs, farming, services
- Geographic filtering by Irish county
- Price range filtering
- Comprehensive data extraction (20+ fields)
- AI-agent compatible via Apify MCP

Compatible with Claude, ChatGPT and AI agents via Apify MCP.
